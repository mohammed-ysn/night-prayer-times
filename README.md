# Night Prayer Times

A calculator for Islamic night prayer times. Automatically fetches today's Maghrib and tomorrow's Fajr for London, then calculates the end of ʿIshāʾ (the middle of the night, with ⅓ shown as another opinion) and the start of the last third of the night.

## Development

```bash
pnpm install
pnpm dev
```

## Build

```bash
pnpm build
```

Outputs static files to `dist/` for deployment to GitHub Pages.
